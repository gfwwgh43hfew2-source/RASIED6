# نظام مصاريف الموقع

نظام لإدارة **مصاريف الموقع** والشركات المتعاملة (رمل · أسمنت · معدات) مع الحفاظ على نفس تصميم ERP الأصلي.

## التشغيل

```bash
python3 -m http.server 8000
```

ثم افتح: http://localhost:8000

- بدون إعدادات Supabase يعمل بوضع **Demo** (بيانات محلية في المتصفح).
- مع `js/config.js` (Supabase) يعمل سحابياً مع تسجيل دخول.

## الوحدات الأساسية

| القسم | الوظيفة |
|--------|---------|
| لوحة التحكم | ملخص مصاريف الشهر، أعمال الشركات، الخزائن |
| تسجيل المصاريف | إضافة مصروف بفئة (عمالة، مواد، معدات، نقل…) |
| التقرير الشهري | تقرير كامل للشهر + طباعة + تصدير Excel |
| الشركات المتعاملة | شركات الرمل والأسمنت والمعدات |
| أعمال الرمل/الأسمنت/المعدات | تسجيل الشغل المأخوذ من كل شركة |
| الخزائن والسندات | كما في النظام الأصلي |
| الموارد البشرية | موظفين · حضور · مرتبات |
| النظام | مستخدمون · نشاط · إعدادات · إدارة |

## ملاحظات

- التصميم (Sidebar / Dashboard / الثيم) لم يُغيَّر.
- بيانات Demo التجريبية تُحفظ تحت المفتاح `site_expenses_demo_v1`.
